AI Prompt Quality Analyzer

This browser-based tool helps students and beginner AI users improve prompt writing. It analyzes a prompt using five prompt-quality categories, explains what works, identifies weak areas, and generates an improved version that is easier to reuse in another AI system.

How to use this tool

  1. Type or paste a prompt into the text area.
  2. Click Analyze Prompt.
  3. Review the overall score, category ratings, strengths, weaknesses, and suggestions.
  4. Copy the improved prompt and test it in your preferred AI tool.

What this MVP checks

  • Clarity
  • Specificity
  • Role Assignment
  • Constraints
  • Output Format
